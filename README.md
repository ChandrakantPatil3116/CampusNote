# 📚 CampusNote - Student Notes Sharing Platform

A full-stack web application that enables students to upload, organize, discover, and download academic notes. The platform is designed to simplify knowledge sharing within educational communities by providing a centralized repository for study materials categorized by subject, semester, and course.

---

## 🚀 Project Description

**CampusNote** is a student-centric notes sharing platform that allows users to contribute and access academic resources with ease. Students can upload notes in PDF or document formats, browse materials uploaded by others, search for specific subjects, and download study resources anytime.

The project aims to encourage collaborative learning while providing a clean, responsive, and user-friendly interface. It is being developed following real-world software development practices, with continuous feature additions and improvements.
